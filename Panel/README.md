# CPN Panel

Interfaz React y Next.js del panel de administración de Control Panel Network.

## Rutas actuales

- `/`: acceso al panel.
- `/dashboard`: resumen del servidor, recursos, servicios y actividad reciente.

El diseño parte de las pantallas del proyecto Stitch `NT&DBN Panel` y del sistema visual Apple instalado mediante GetDesign. Los archivos originales descargados se conservan en `stitch-reference/`.

## Desarrollo

```bash
npm install
npm run dev
```

## Validación

```bash
npm run lint
npm run typecheck
```

El proyecto continúa en desarrollo y todavía no incorpora autenticación ni datos reales del backend.
