CPN Control Panel Network

A Rust hosting control panel from News Targeted: sites, mail, databases, SSL, and day-to-day ops on AlmaLinux and friends.

Get the install command View on GitHub

Alpha only. Tip tracks 0.2.6-alpha (not a stable 1.x). Prefer a disposable VPS or VM, keep backups, and read the platform support notes before important hosts.

Install and upgrade

Prefer these short curl -fsSL pipes against this host. Scripts stay at plain URLs. Use GitHub raw only when the site is down (see fallback below).

Install Run as root or with sudo available 
curl -fsSL https://cpn.newstargeted.com/install.sh | bash
Upgrade Package upgrade, then auto panel maintenance when installed 
curl -fsSL https://cpn.newstargeted.com/upgrade.sh | bash
Pin a release -b / --ref example 
curl -fsSL https://cpn.newstargeted.com/upgrade.sh | bash -s -- -b v0.2.6-alpha.43
Fallback if the site is down

GitHub raw on stable. Hosts without curl can use wget -O - URL | bash the same way.

Install (GitHub raw) 
curl -fsSL https://raw.githubusercontent.com/Control-Panel-Network/CPN-Control-Panel-Network/stable/scripts/install.sh | bash
Upgrade (GitHub raw) 
curl -fsSL https://raw.githubusercontent.com/Control-Panel-Network/CPN-Control-Panel-Network/stable/scripts/upgrade.sh | bash
